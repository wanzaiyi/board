语法一点

Grammar ＋ 每日一句

need 作情态动词

need do · needn't do

后面直接跟动词原形，不加 to。多用于否定句和疑问句，needn't 就是“不必”。

You needn't get up early tomorrow.
明天你不必早起。

need 作实义动词

need to do

当普通动词用：第三人称单数加 s，否定用 don't / doesn't need to do。

He needs to have a rest.
他需要休息一下。
一句话记住：needn't 后面不加 to，needs 后面必加 to
每日一句
I need to get some sleep now.
我现在得去睡一觉了。

物理公式

Physics 凸透镜成像规律
1/u + 1/v = 1/f
u 物距　·　v 像距　·　f 焦距
光轴示意图：透镜两侧各有一个焦点 F、二倍焦距点 2F
物距 u像的性质像距 v应用
u > 2f倒立 · 缩小 · 实像f < v < 2f照相机
u = 2f倒立 · 等大 · 实像v = 2f测焦距
f < u < 2f倒立 · 放大 · 实像v > 2f投影仪
u = f不成像（平行光）无限远探照灯
u < f正立 · 放大 · 虚像与物同侧放大镜
一倍焦距分虚实，二倍焦距分大小
实像异侧倒，虚像同侧正
成实像时：物近、像远、像变大
